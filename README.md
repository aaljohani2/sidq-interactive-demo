# صِدق | SIDQ / MIDA

## Interactive Acrylic Prototype

**تجربة ثلاثية الأبعاد لمنصة التحقق الفيزيائي المستقل**، تعرض تصميم نموذج أكريلك 60×40 سم، والمكوّنات الإلكترونية، والموصلات، وأزرار التشغيل، وحالات النظام في واجهة عربية تفاعلية.

**[فتح التجربة](https://aaljohani2.github.io/sidq-interactive-demo/)**

### ماذا تتضمن التجربة؟

- مجسم ثلاثي الأبعاد قابل للتدوير والتقريب مع زوايا علوية وأمامية وجانبية، ووضع تفكيك الأجزاء.
- محرك FIT0186 مع Hall Encoder وقرص لقياس السرعة البصرية وسيرفو لاختبار تغيّر الحمل.
- وحدتا ESP32-S3 منفصلتان: Telemetry وTrusted Physical Witness.
- حساسات INA219 للطاقة وADXL345 للاهتزاز وOptical RPM للسرعة.
- منظومة تغذية تشمل 12V و5V، وقيادة المحرك، والمصهر، وزر الإيقاف الطارئ.
- موصلات بألوان وظيفية ومسارات قابلة للإظهار والإخفاء: طاقة، تحكم، Telemetry، وشاهد مستقل.
- أزرار التشغيل والإيقاف، إعادة الضبط، التحقق النشط، وتحرير الإيقاف الطارئ.
- أربعة سيناريوهات: التشغيل الطبيعي، العطل الفيزيائي، التلاعب بالقراءة، وإعادة بث البيانات.
- لوحة مؤشرات ومنحنى تفاعلي لمقارنة بيانات القناتين.

### تجربة التشغيل

1. استخدم **مفتاح الطاقة** لتهيئة النظام.
2. اضغط **بدء التشغيل**.
3. اختر أحد الأزرار الملونة لاختبار الحالة.
4. اضغط **تنفيذ التحقق النشط** وشاهد الاستجابة.
5. استخدم **إيقاف المحرك** أو **الإيقاف الطارئ** حسب الحاجة.
6. لإعادة التشغيل بعد الإيقاف الطارئ، حرّر زر الطوارئ ثم اضغط بدء التشغيل.
